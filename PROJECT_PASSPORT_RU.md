# Паспорт проекта: ManuscriptPilot

**Автор:** [ФИО, организация]  
**Категория:** University  
**Формат:** веб-приложение для самостоятельной проверки рукописей и подготовки ответов рецензентам.

## 1. Какую проблему решает проект?
Исследователю трудно систематизировать замечания и проследить связь между комментарием, исправлением рукописи и ответом. Продукт объединяет эти действия. Аудитория — исследователи, магистранты, докторанты и исследовательские офисы.

## 2. Как пользоваться проектом?
Вход: текст, DOCX или текстовый PDF и замечания рецензентов. Операция: локальная проверка по правилам, просмотр предложения и его явное принятие автором. Результат: измененная рукопись DOCX, черновик ответа и отчет. PDF доступен только для чтения. Демопроект использует исключительно искусственные данные и заранее подготовленные предложения.

## 3. Как тестировать проект?
Выполните задание из MVP_TEST_RU.md. Без ключа API демосценарий работает локально. По результатам фактической проверки: 6 модульных и 2 автоматизированных браузерных теста прошли; сборки Next.js и статической демоверсии успешны; в браузере проверены переключение языков, принятие правки, связанный ответ, сохранение после обновления и скачивание DOCX. Из XML скачанного DOCX извлечено измененное предложение аннотации. Настоящий вызов модели с ключом не проверялся.

## 4. Какова практическая польза проекта?
Автор получает прослеживаемую связь между замечанием и предложенной правкой, а также черновики документов. Система не доказывает научную достоверность и не гарантирует соответствие требованиям журнала. Показатели экономии времени не измерялись.

## 5. Как использовать или адаптировать проект в других образовательных организациях?
Развернуть приложение самостоятельно по DEPLOYMENT.md, использовать синтетическую демонстрацию для обучения и при необходимости расширить правила или интерфейс. Для реальных рукописей организация должна самостоятельно оценить допустимость передачи отрывков внешнему поставщику ИИ и условия хранения браузера.

## Вклад и зависимости
Проект создан при помощи Codex; сведения о вкладе автора заполняются в CONTRIBUTION_DECLARATION.md. Среда: Node.js, Next.js, React, TypeScript; зависимости перечислены в package.json и lock-файле. Данные проекта хранятся в браузере; очистка хранилища удалит их. Живой ИИ необязателен и требует настройки сервера и согласия на отправку выбранного отрывка. Ограничения приведены в README.md.
